# 5분 자동 수집과 로컬 확인

`.env.local`에 기존 `ARKM_API_KEY`를 설정한 후 별도 터미널에서 실행한다.

```sh
npm run market:watch
```

즉시 첫 수집 후5분마다 실행한다. 기본12회·최대84 GET 후 종료하며, 이 프로세스가 실행 중일 때만 수집한다. 더 긴 확인은 `npm run market:watch -- --max-runs 24`처럼1~288회로 지정한다. 이 한도는 프로세스당 요청 상한이며 계정의 일일 예산이 아니다. 자동 재시작을 설정하지 않는다.

다른 터미널에서 `npm run ui`를 실행하고 <http://127.0.0.1:4173/#live>를 연다. 웹은60초마다 저장본을 다시 읽으므로 수집 완료 후 반영까지 최대 약60초 걸린다. 상단에서 원본 관측 시각·경과 시간·자동 수집 실행 수/다음 예정/중단 기록을 구분한다. 가격·유통량 차트에 수집 이력이 쌓이지만 없는 과거 자료를 만들지는 않는다. 실행 기록은 프로세스 생존을 보장하지 않으며 예정 시각을 지나면 확인 필요로 표시한다.

Ctrl+C로 중지한다. 진행 중인 수집은 최대120초 예산 내에 정리한 뒤 종료한다. 한 번이라도 수집 실패/429/권한 오류/저장 한도/다른 writer 충돌이 발생하면 즉시 중단하고 이전 정상 자료를 유지한다. 원인을 확인한 뒤 수동으로 재실행한다. 비정상 종료로 잠금이 남으면 모든 관련 프로세스의 종료를 확인하고 `.scheduler-lock` 또는 `.writer-lock`을 수동 복구한다. 실행 중 잠금을 삭제하지 않는다.

이 단계는 로컬 JSON 저장이며 Supabase/PostgreSQL 자동 저장은 연결 전이다. 기존5000관측/2MiB 한도에 도달하면 발행을 멈춘다. 자동 삭제나 롤업은 하지 않는다. 공급자 계정의 잔여 크레딧·기간·단가는 별도 확인이 필요하다. 세부 결정은 [ADR0041](adr/0041-five-minute-market-collection.md)을 따른다.
