# Atlas 저장 관측 대시보드

개인 개발용 로컬 스테이블코인 탐색 화면이다. [ADR0086](adr/0086-unified-stored-observation-dashboard.md)이 데이터 의미와 경계를 고정한다.

## 질문과 화면

| 질문 | 표시 | 해석 |
| --- | --- | --- |
| 선택 코인의 규모 또는 가격은 얼마였나? | 마지막 관측 KPI·원래 수량 표 | CIRCULATING·CHAIN_TOTAL·PRICE를 선택하며 금액을 서로 합산하지 않음 |
| 저장된 구간에서 무엇이 달라졌나? | 관측 구간 변화·이전 동기간 비교·추이 | 첫/끝 변화와 이전 구간 마지막 값 비교를 구분. 이전 자료 부족/0 분모/표본화는 비교 불가 |
| 체인별 차이와 그 근거는 무엇인가? | CHAIN_TOTAL 선·막대와 상세 표 | 막대 또는 그래프를 선택하면 해당 관측이 있는 페이지와 상세를 표시. 미확보 체인은0이 아님 |

```text
제목 / 관측 시각 의미                        저장본 다시 읽기
코인 | 지표 | 체인                          기간
마지막 관측(크게)      구간 변화       이전 동기간
넓은 추이                            체인 비교/구간 범위
상세 관측: 정렬 → 페이지 → 원래 수량·기준/관측 시각
마지막 수집 기록 / 저장 완료 / 갱신·오류 상태
```

본문과 표는 왼쪽 정렬, 숫자는 tabular 숫자다. 큰 마케팅 표어와 동일 크기 KPI 카드 대신 한 개의 주요 수치와 넓은 추이에 면적을 준다. 지표가 코인 전체이면 체인 비교 대신 관측 범위를 표시하여 다른 범위를 혼합하지 않는다. 선택으로 체인 공급량 비교에 진입한다.

## 시각 계획과 대조

frontend-design의 계획→대조→구현→스크린샷 비평을 적용했다. 기본 토큰은 canvas `#162333`, panel `#203247`, ink `#edf3fa`, muted `#a8b7ca`, accent `#75b5ff`, amber `#e8bc72`다. 라이트는 차가운 회색 바탕과 흰 패널을 쓴다. Avenir Next는 영문/수치, Apple SD Gothic Neo·Malgun Gothic은 한국어를 담당한다. 본문15px·제목25px·주요 수치39px·표12px이며 모바일은 주요 수치를 남기고 비교를 아래로 옮긴다. 임의로 다른 폰트를 다운로드하지 않는다.

초안의 동일 크기 카드 세 개와 큰 표어는 데이터 대비 장식 면적이 커지는 문제 때문에 제외했다. 서로 다른 규모의 체인 비교에는 선 그래프와 원래 수량의 막대/표를 함께 제공하며 비율 파이 차트는 추가하지 않는다. 축은 선택 값에 맞추며 그 사실을 차트 아래에 표시한다. 출처명은 대시보드에 표시하지 않는다.

참고 URL은 2026-10-24 읽기 도구로 확인했다.

- [Tremor Templates](https://blocks.tremor.so/templates): Overview의 개요/분석 구성, Insights의 URL 필터와 상세 표 탐색을 참고했다. 템플릿 코드를 복사하거나 Next.js를 도입하지 않았다.
- [shadcn Charts](https://ui.shadcn.com/charts/area): 축·범례·툴팁의 구성과 강조를 참고했다. React/Recharts 의존성은 추가하지 않았다.
- [ECharts Examples](https://echarts.apache.org/examples/en/index.html), [Grafana Play](https://play.grafana.org/): 도구에서는 JavaScript 필요 안내만 반환했다. 실제 예제/운영 화면을 확인했다고 간주하지 않았다.

기존 프로젝트의 SVG 기반을 하나의 차트 구현 방식으로 유지했다. 새 라이브러리/CDN/폰트 요청 없이 범례·축·원래 값 툴팁·키보드 선택·공백 분리·극값 보존 축약을 구현했다. 원형/관계/분포 차트는 이번 질문에 필요하지 않아 넣지 않았다.

## 실제 데이터 흐름과 실행

```text
서버 수동 CLI → 허용 응답 projection(0600)
              → 원래 시각·십진 문자열 정규화 + 관측 ID 중복제거
              → hash snapshot + 원자적 index / 별도 마지막 수집 상태
로컬 GET /market-data.json → 검증 → 공통 조건 모델 → KPI / SVG / 상세 표
```

`npm run ui`로 `http://127.0.0.1:4173`을 연다. 다른 프로세스가 사용하면 `npm run ui -- --port 4174`로 별도 포트를 선택한다. 현재 서버는 이미 수집된 로컬 JSON을 읽으며 새 환경변수는 필요하지 않다. 저장본을 보유하지 않은 PC에서 실제 관측이 자동 생성되지는 않는다.

기존 수동 수집은 `npm run market:collect`다. 사용자가 실행할 때 외부 Arkham API의 고정3코인 market/holders와 networks/status만 최대7GET으로 읽는다. 서버의 `ARKM_API_KEY`가 필요하며 shell 또는 비공개 `.env.local`에서 기존 workspaceEnvironment가 읽는다. 브라우저에 키를 입력하거나 전달하지 않는다. 실행 허용 범위와 키 설정은 [새 PC 안내](NEW_PC_SETUP.md#시장-자료의-수동-갱신)를 따른다. 이번 구현에서는 이 외부 명령을 실행하지 않았다.

기존 DB 읽기는 `npm run ui -- --database --database-env <비공개-reader-환경파일>`로 명시 선택한다. 서버 전용 `DATABASE_URL`과 필요한 경우 `DATABASE_CA_FILE`을 사용하며 DB 초기화/수집은 실행하지 않는다. 이번 검증은 DB에 접속하지 않았다. Allium/API의 연구 원문·1,225점 가격 이력·상위 보유자 표본은 대시보드 데이터로 승격하지 않았다.

## 현재 연결과 제한

현재 로컬 JSON은 USDC·USDT·RLUSD의 기존 시장 관측이며, 2026-10-21~23의2,244개 관측은 여러 지표의 합계다. 기준시각 미제공과 원래 요청/보고서 관측시각은 그대로 남긴다. 페이지 필터는 저장본 마지막 관측 기준이며 벽시계의 오늘/실시간 수집을 뜻하지 않는다. 마지막 수집 상태와 저장 완료시각을 표시하지만 모든 과거 실패 시도의 별도 타임라인은 제공하지 않는다.

기존 저장 읽기 보고서8개·111항목은 자산 프로필/비교에서 제공한다. 로컬 JSON 모드의 일별 전송량·저장 조사·등록 확장 경로는 비활성이다. 장기 이력은 이 JSON에 없고 DB 읽기의 현재 데이터는 이번 실행에서 확인하지 않았다. 누락을 목업이나0으로 채우지 않는다.

수집 주기·새 실제 호출·새 공급자·페이지 확대·실패 재시도는 추가하지 않았다. 현재 승인된 단발 경로의 retry0 정책을 유지한다. 재시작 후 같은 projection을 입력하면 중복 제거되지만, 새 시각의 새 수집은 별도 관측으로 저장된다. 과거/현재 공급량의 서로 다른 정의와 연구 표본의 단위 미확정을 그대로 보존한다.

## 검증

`npm run check`에 공통 조건·계열 분리·정밀도/0·이전 기간·공백·축약·URL·재입력 시험을 포함했다. 실제 브라우저에서 저장 관측·필터/표/차트·페이지·뒤로가기·키보드 상세 선택·503/404/잘못된 JSON 후 이전값·빈 저장소·초기 오류/복구·dark/light·390px·외부 요청0을 검사한다. 이번 최종 실행 결과는 인계문에 기록한다.
