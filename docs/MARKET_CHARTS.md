# 저장 시장 그래프

`npm run ui`의 시장 화면(`#live`)에서 코인을 고르고 가격(USD)·유통량(tokens)·코인 전체 총공급량(tokens)을 선택한다. Overview 공급량 순위와 시장 코인/네트워크 순위에도 해당 지표의 작은 추세선을 표시한다. 기존 네트워크별 공급량 이력은 별도로 유지한다.

## 기간과 관측 선택

기본 JSON 모드에서 24H·7D·30D는 해당 시계열의 **마지막 저장 관측 시각**을 끝으로 하는 구간이다. 전체는 확보한 이력 전체이며 마지막 관측 시각을 함께 표시한다. 현재 시각까지의 실시간 시세나 완전한24시간/7일 자료를 뜻하지 않는다. 기간 선택·새로 읽기는 외부 API를 호출하지 않는다.

[DB 읽기 모드](SUPABASE_SETUP.md#4-ui와-실패-복구)는 **DB 조회 시각** 기준 최근30일을 제공한다. 응답에 표시된 시리즈별 한도(100~200점)를 넘으면 양끝을 포함한 실제 관측 표본을 표시하며 원본 수·표본 여부·조회 범위는 상세 자료에서 확인한다. ‘조회 범위’는 이 제한된 구간이고 기간 밖 최신값은 요약/상세에만 남긴다. 표본화한 선은 기간 내 모든 급변이나 최고/최저를 보장하지 않는다.

마우스 이동·터치 또는 차트에 Tab으로 진입한 뒤 좌우 화살표로 관측을 선택한다. Home/End는 처음/마지막 관측으로 이동한다. 선택할 때 툴팁에 정확한 수량·원본 관측 시각을 표시하며, 출처 버튼은 선택한 관측의 원본 수량·추출 위치·입력 hash를 연다.

Overview에서 토큰을 선택하면 자료가 있는 여러 네트워크를 서로 다른 색의 선으로 겹쳐 표시한다. 네트워크 필터의 기본값은 모든 네트워크다. 각 선은 자체 관측 시각을 유지하며 합산·보간·누락0 대체를 하지 않는다. 모든 선은 공통 시간축과0 기준 공급량 축을 사용한다. 범례에는 네트워크별 최신 수량과 기본정보 버튼을 표시한다. 위아래 화살표로 네트워크를 바꾼다. 차트 하단에는 가장 최근 실제 관측의 업데이트 시각만 표시한다. 조회 시각·관측 수·내부 저장 설명은 본문에서 제거한다.

## 그래프 의미

- 같은 코인·deployment·지표·공급자·endpoint·selector의 관측만 연결한다. 같은 시각의 중복은 기존 시계열 정렬의 마지막 ID를 선택한다. 다른 공급자나 지표를 이어 붙이지 않는다.
- 누락은 빈 상태, 단일 관측은 점과 추세 미확보로 표시한다. 이력 확보를 위해 자동 조회하거나 가상의 과거 값을 만들지 않는다. 기존 입력에 없던 관측은 새로 수집해 저장해야 늘어난다.
- 선과 영역은 저장 관측 사이의 시각적 연결이다. 그 사이 실제 시세·공급량이나 거래를 관측한 증거가 아니다. 사용자 요청으로 첫 점과 마지막 점의 차이인 ‘관측 구간 ±수량’ 요약은 표시하지 않는다. 현재값·원본 관측값·시각은 유지한다.
- 공급량 차트의 세로축은0에서 시작해 미세한 원본 변화를 과장하지 않는다. 가격 차트는 관측 범위를 확대해0에서 시작하지 않을 수 있다. 축의 긴 소수는 생략 표시할 수 있으며 선택 관측의 원본 수량은 생략하지 않는다. 수량 비교·차이는 bigint로 계산하고 화면 좌표만 제한된 Number로 변환한다.
- 작은 추세선은 행에 표시된 공급량 지표의 확보된 전체 이력이다. 행마다 기간과 관측 수가 다를 수 있다. 가격 추세나 동일한7일 구간으로 해석하지 않는다.

현재 저장 자료의 일부 가격은1점뿐이다. 실제 자료가 누적되면 같은 차트가 선과 영역을 표시한다. 거래량 정의와 수집 예산의 미확인 조건은 [공식 문서 재확인 기록](research/arkham-volume-and-budget-review.md), 지표 분리는 [ADR0038](adr/0038-overview-scenario-results.md)을 따른다.

## 로딩 표시

전체 현황·시장·검증/프로필/비교/보고서·근거 상세·목데이터 차트의 첫 조회는 스켈레톤을 표시한다. 스켈레톤에 예시 수량이나 판정을 넣지 않으며 장식 요소는 접근성 트리에서 제외한다. 조회 영역은 aria-busy를 표시하고 성공/실패 시 해제한다. 실패하면 스켈레톤을 지우고 기존 오류 안내를 표시한다. 정상 자료가 이미 있는 재조회는 기존 내용과 원래 관측 시각을 유지한다. 동작 줄이기 설정에서는 스켈레톤 애니메이션을 멈춘다.

## 일별 유통량·발행량

[ADR0047](adr/0047-daily-minted-and-relative-comparison.md)에 따라 Overview 자료는 `일별 유통량`·`일별 발행량`이다. 오늘까지 제공된 최신 일별 기준일을 표시하며, 실시간 수량이나 오늘 하루의 최종 확정값을 뜻하지 않는다. 기본1년,3M은90일 전부터,1Y는365일 전부터 양끝을 포함한다(최대91/366개 일별 관측).

기본 `증감률 (%)`는 각 네트워크의 선택 구간 첫 관측 대비 변화를 공통 축에 표시한다. 작은 규모의 XRPL도 변화를 읽을 수 있다. 기준값0은 계산 불가로 안내한다. `공급량 규모`를 선택하면 실제 수량의 공통0 기준 축으로 전환하며0인 원본도 유지한다. 범례와 tooltip은 실제 수량을 그대로 표시한다. tooltip에는 해당 관측일과 증감률 기준일을 함께 표시한다.

DeFiLlama의 coin/network 유통량과 발행량은 별도 지표이며 단일 계약 totalSupply 인증이 아니다. 원문 circulating/minted가 없으면 서로 대체하지 않는다. Arkham 자료는 Market에서 유지하고 Overview의 일별 이력과 접합/자동 fallback하지 않는다. 일별 자료가 없으면 미확보다. 다운로드 시각은 DB provenance로 별도 보존한다.
