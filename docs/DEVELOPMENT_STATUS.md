# 현재 개발 상태

기준: 2026-10-21. 이 문서는 다른 PC/새 작업 세션이 읽는 Git 공유 인계다. 로컬 `.state`나 API 키가 없어도 코드의 범위와 다음 행동을 파악할 수 있도록 유지한다.

## 완료 범위

- EVM/ERC-20·TRON 읽기와 프로그램이 생성한 격리 사설 Fixture 검사.
- Solana mint/명시 Token Account, XRPL issuer/명시 holder trust-line의 공통 읽기. 공개망 거래·서명·실제 관리자 권한 행사는 없다.
- 로컬 저장 근거의 항목별 현황, 자산 프로필·비교, 보고서 문서. 소스 확인과 실제 실행 판정을 구분한다.
- 실제 저장 시장 자료 화면 `#live`: 코인 전체 유통량 순위, 같은 코인의 체인별 총공급량, 관측 이력·원본 수량·출처, 공급자 네트워크 상태. UI는 다크/라이트·모바일을 지원하며 순위 행 선택으로 비교 대상을 바꾼다.
- 등록 모델: coin/network/deployment ID, 계약·mint·issuer+currency 식별. 현재3코인/4네트워크/8발행 자산. 등록은 Adapter 지원 인증과 별도다.
- Arkham 체인별 `totalSupply`와 전체 `circulatingSupply`를 분리한다. XRPL `gateway_balances.obligations`는 별도 범주이며 순위·합계에 섞지 않는다.
- 새 PC 환경 진단·빈 설정 생성·키를 출력하지 않는 읽기 CLI wrapper·고정14보고서 로컬 이동. [설정 순서](NEW_PC_SETUP.md).

현재 원본 집합을 가진 PC에서는15보고서/202항목, 시장 관측14개를 재구성할 수 있다. 이는 보존된 과거 자료이며 새 PC의 새 관측·새 실행 결과가 아니다. 원본 집합은 Git에서 제외한다. 서버의60초 갱신은 저장본을 다시 읽을 뿐 외부 API를 호출하지 않는다.

## 아직 구현하지 않은 것

- 서버의 주기적 외부 수집, 계정별 rate/credit 예산,429/backoff 수집기, 자동 공급자 전환.
- 운영 DB·보존기간 정리·서비스 배포·공개 호스팅.
- 실제 안전성 점수/등급. 가상 `Market preview`의 점수는 제품 판정이 아니다.
- 네이티브/브리지별 중복 제거, 서로 다른 공급자의 공급량 정의 통일, 동일 coin/network의 복수 deployment 매핑.
- Arkham WebSocket. 현재 목표에는 도입하지 않기로 했다.

## 다음 개발 단위

먼저 새 PC를 `npm ci` → `npm run setup` → `npm run doctor`로 준비하고, 실제 자료가 필요하면 별도 이동 파일을 가져와 두 publisher를 실행한다. 이후 외부 수집기를 구현할 때는 웹 요청과 분리된 서버 작업으로 하고, 계정 한도·크레딧을 확인한 작은 예산부터 시작한다. 사용자 화면 수가 외부 요청 수를 늘리지 않도록 공유 저장본을 사용한다.

수집 실패 시 마지막 정상값·원본 관측 시각·실패 상태를 보존한다. 누락·명시적0·메서드 오류·미지원은 다르다. XRPL과 Arkham의 다른 지표를 단순 fallback으로 서로 대체하지 않는다. 새 체인/토큰은 먼저 registry와 공급자 식별자 출처를 연결하고 미확보 범위를 표시한다.

## 검증 기준

직전 Git 체크포인트는 `c3e9557`이며 연구형 시장 화면과 기존 엔진 검사225개가 통과했다. 이번 이동 기능과 새 checkout 보정 후 전체 검사는231개 통과(실패·취소·skip0)했다. 키/보고서/의존성 없는 격리 소스에서 npm ci, 환경 진단,14원본 복원,15보고서/202항목·14시장 관측의 바이트/hash·시각/판정 일치, 두 화면의 Chrome 확인을 수행했다. 고정 TRON compiler는 공식 로더로 준비하고 무변경 재사용·손상 시 무실행/무재다운로드 거부를 확인했다. 초기 검사에서 실제 Solana 보고서와 TRON cache에 대한 숨은 의존성을 발견해 보정했다. 현 실행 환경은 macOS/ARM64, Node25.2.1이다. 같은 머신의 격리 checkout 검증과 물리적으로 다른 PC/OS에서의 검증을 구분한다.

큰 기술 결정은 [ADR0035](adr/0035-stored-market-observations.md), [ADR0036](adr/0036-portable-local-workspace.md)를 따른다. 실제 키·환경변수 값·RPC URL·보고서 원문·개인 SSH 설정은 이 문서에 기록하지 않는다.
