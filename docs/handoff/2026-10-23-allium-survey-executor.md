# Allium 단발 조사 실행기
- 목표: ADR0060 후속의 수동 단발 실행 경로·영속 예약·호출 예산·비공개 영수증 구현. 실제 지원 조사·공급량 DB/UI·일별 수집은 아직 미완료.
- 끝난 것: ADR0061과 allium:execute usage/execute/status/review. 고정 등록/SQL 재생성 대조, 검토 authorization SHA·SQL/API limit·조직/키 지문·원래 usage/통제 증거 결합. usage는 하루1GET, 실행은 조직 할당기간당 한 묶음·UTC 날짜 독점 슬롯으로 최대3run/39HTTP와 전체 예산을 영속 예약. 요청 전 intent/snapshot·파일/디렉터리 fsync, raw archive 우선·해시 영수증. 불명 UNKNOWN·자동 재호출/환급/슬롯 삭제 없음. 복구는 네트워크 없는 원문 review만. 실제 usage GET1회 HTTP200; 강제 과금 한도 UNCONFIRMED로 조사 create/run0·11배포 NOT_TESTED·XRPL2개 보류 유지. 테스트의 통제 증거를 실사용하지 않는다.

- 다음 행동: 실제 공급자 강제 한도의 진행 중 비용 포함 여부·초과과금 중지·다른 소비자 통제와 안정된 조직 식별 근거를 확보한다. usage 응답만으로 authorization true를 만들지 않는다. 현재 usage는 원래 시각부터1시간만 유효하고 같은 날 재조회하지 않는다. 조건 충족 후 새 날짜의 usage와 검토 authorization으로 소량 실제 지원 원문 확보→체인별 식별자/decimals/날짜/정의 확인→별도 Allium 공급량 저장/조회→기본 UI→동등 보조→일별 수집. 로컬 슬롯을 지우거나 다른 root/PC로 복제해 재실행하지 않는다. DeFiLlama 경제적 유통량과 자동 대체/합산/그래프 연결 금지. 다른 세션의 AGENTS.md·docs/handoff/README.md·tools/intelligent-router/adapters/renew.py·evaluation/test_lead.py 변경과 기존 미추적 router-lead-review 인계문은 이번 범위 밖으로 보존.
