# Agent 인계문

작업 경계에서 `YYYY-MM-DD-<주제>.md`로 하나 쓴다. 다음 세션은 가장 최근 파일만 읽는다. 내용을 옮겨 적지 말고 읽을 파일을 가리킨다(3000자 이하). 키·환경변수 값·RPC URL·보고서 원문은 쓰지 않는다.

아래 항목 이름은 `tools/intelligent-router/adapters/renew.py schedule`이 검사한다. 빠지면 자동 새 대화를 예약하지 않는다.

```markdown
# <주제>
- 목표:
- 끝난 것:
- 변경 파일: (경로만)
- 검증: (명령·rc·pass/fail 수를 직접 적는다)
- 기다리는 것: (백그라운드 작업·Lead id와 결과 위치, 없으면 없음)
- 다음 행동:
- 사용자 확인 필요: 아니오 | 예 — <무엇을> (예이면 자동 새 대화를 예약하지 않는다)
- 읽을 파일: (진행 기록·결정 문서·ADR 경로)
```
