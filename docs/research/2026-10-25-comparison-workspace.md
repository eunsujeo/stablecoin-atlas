# 자산 비교와 검증 비교 정리

사용자 ‘자산비교’·‘검증 비교’ 정리 요청에 따라 [ADR0103](../adr/0103-profile-and-verification-comparison.md)을 구현했다.

## 수행 경로와 확보 자료

기존 기본/Atlas의 자산 비교는 저장된 읽기 보고서만 나란히 보여주었다. 공개용 소스 발췌26프로필을 사용하는 자산 비교를 기본 보기로 추가하고, 기존 보고서 표는 검증 비교로 명명했다. 프로필은 자산+네트워크+검토 범위를 선택지에 표시한다. 두세 개의 프로필에서 식별자·검토일·범위·기능별 조건과 근거를 함께 확인할 수 있다. 두 보기의 선택은 전환 후에도 유지한다.

서로 다른 프로필의 scope-0은 같은 기능을 뜻하지 않을 수 있어 그룹+항목명이 같은 경우에만 같은 행으로 표시한다. 개별14기능과 합쳐진 전송·승인 항목은 별도 행이며 미수록을 부재나 비적용으로 바꾸지 않는다. 기존 소스 상태·원래 판정·공개 문서/상세 근거 연결은 보존했다. 보고서2~3개 선택과 중복 선택 차단·현재 항목 수 안내를 정리했다.

## 실패·원인과 수정

최초 브라우저 검사는 통과했다. 상세 근거 닫기/포커스 복귀 검사를 추가한 실행에서는 close 이벤트가 전달되기 전에 포커스를 검사해 실패했다. 제품 동작은 유지하고 검사 도구가 실제 포커스 복귀를 기다리도록 보완했다. 구현 검토 중 Atlas 진입 포커스가 기본 보기에서 숨겨진 기존 보고서 제목을 가리켜 선택 버튼으로 옮겼다. 후속 브라우저 검사에서 초기 navigate가 비교 모듈의 버튼 생성보다 먼저 실행되어 null focus TypeError가 드러났다. 모듈 실행 순서에 의존하지 않는 정적 비교 선택 영역으로 연결하는 보완을 적용했다. 로컬 Lead 검토 b0aa363f7c784b3e9d0355788915e451은 proceed로 정적 영역 한정·초기/왕복/모듈 지연·콘솔 예외 재검증을 요구했다. 보고서 상태 문단은 래퍼 추가 후에도 원래 여백을 유지하도록 보완했다. 로컬4399포트에서 별도 JSON 미리보기를 열고 기존 서버는 유지했다.

## 미확인과 경계

현재 배포 연결·실제 권한 행사·입출금 서비스·지원 판정을 추가 검증하지 않았다. 소스 비교는 원래 검토 범위와 한계를 유지한다. 새 외부 API/RPC/compiler/다운로드·키·DB 변경0이다. 브라우저 요청은 로컬로 제한하고 원문 archive·endpoint를 공개하지 않았다. 프로필 비교용 정적 자산의 정상 응답과 렌더링 후 조작/스크린샷을 별도로 확인했다.
