# Allium 로컬 실제 수집 — 2026-10-23

[ADR0076](../../adr/0076-user-authorized-local-live-collection.md)의 사용자 승인 수동 최초 1묶음 결과다. 기존 [11배포 조사](survey-2026-10-23.md)와 원문·예약·UNKNOWN 이력은 그대로 보존했다. 이번 공급량/전송량 원문·승인·receipt·검토 manifest·projection은 고정 비공개 `.state/allium-executor/live-once`에 따로 보존한다. 원문·계정/query/run 식별값과 개별 입력 hash는 Git/웹에 게시하지 않는다.

## 실제 관측

## 개별 SQL 검토와 보존

각 성공 응답에서 echo가 달라 원래 UNKNOWN receipt를 보존하고 다음 job을 중단했다. 고정 요청 SQL과 각 전체 echo를 오프라인에서 비교했다. 주석의 line/block 표기·공백/마지막 semicolon·VALUES 괄호·alias AS·TO_VARCHAR/TO_CHAR·두 날짜의 ::DATE/CAST AS DATE만 다르며 대상·주소·문자열·형변환 인자·날짜·조건·정렬·LIMIT가 유지됨을 확인했다. 해당 함수/CAST 표기 근거는 기존 [ADR0066](../../adr/0066-reviewed-sql-echo-and-survey-checkpoints.md)을 따른다.

각 요청/echo/source·receipt·원래 승인 hash에 결합한 별도 SOURCE_REVIEWED manifest로 행·자료형·시각·기간·완전성 검사를 수행했다. 공급량 검토 checkpoint 뒤 미전송 전송량만 실행했고, 전송량 검토 checkpoint는 외부 호출0회였다. 공급량이나 전송량 SQL을 다시 보내지 않았다. 최초 15분 lease를 연장하거나 새 승인을 발급하지 않았다. 두 원래 UNKNOWN receipt·검토 이력·영속 resume 표식과 live-once 소비 기록을 유지한다. 일반 SQL 정규화·새 응답 자동 승인은 없다.

최종 수집 receipt는 SUCCEEDED이며 양쪽 SOURCE_REVIEWED projection을 로컬에 보존했다. 실행 전후 legacy manifest의 기존 bytes/hash·길이·권한은 동일했다. 이는 이번 수집·검토의 성공이며 제품 지원·자산 안전성·공급자 비용 최종성 인증이 아니다. 실제 예산 전환은 TRANSITION_BLOCKED·P UNKNOWN·b_i null·c_i=0, 공급자 통제 UNCONFIRMED·조직/타PC 배타성 UNKNOWN을 유지한다. 일별 자동 수집과 DB/UI 연결은 활성화하지 않았다.

이 수집 단위 이후 [ADR0077](../../adr/0077-offline-live-survey-storage.md)의 별도 오프라인 입력으로 두 저장본을 기존 DB/로컬 표에 연결했다. 새 공급자 호출이나 원래 수집 시각 변경은 없으며 상세 저장 검증은 [저장 현황](../../ALLIUM_SURVEY_DATA.md)을 따른다.
