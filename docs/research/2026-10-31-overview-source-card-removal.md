# 기술 검증 현황 집계 카드 정리

사용자 요청에 따라 전체 현황의 기술 검증 현황에서 `기존 소스 확인`과 `8 / 26` 집계 카드를 제거했다. 검토 자산·네트워크 집계는 유지하고 남은 카드가 화면 폭을 채우도록 배치했다. 기존 검토 프로필·기능·근거 및 상세 화면은 보존했다.

변경 경로는 `web/overview.js`, `web/styles.css`, 기존 브라우저 검증 도구 `tools/source-review-browser-check.mjs`다. 공급자 호출·DB 변경·수집기/FX 변경·직접 운영 배포는 수행하지 않는다.

검증:

- `source .state/dev-env.sh && npm run check`: 종료 0, 879 통과·실패 0·기존 compiler 미보유 관련 8 skip.
- `git diff --check`: 통과.
- 별도 로컬 미리보기와 격리 Chrome에서 개발 HTML 및 `productionDocument()`로 변환한 운영 HTML을 각각 1440px/390px로 확인했다. 카드 제거·자산/네트워크 집계·가로 넘침 없음·JS 오류 0·외부 요청 0을 확인했다. 운영 서비스 자체를 대상으로 한 브라우저 검증은 아니다.
- 임시 검증 도구의 최초 실패는 동일 URL 탐색으로 운영 HTML 변환이 적용되지 않은 것과 `data:` 이미지 요청을 외부 요청으로 집계한 검증 도구 문제였다. 새 문서 탐색 및 네트워크 요청 구분을 수정한 뒤 통과했다. 제품 코드 오류로 처리하지 않았다.

재현: 로컬 웹의 `/#overview`에서 기술 검증 현황을 확인한다. 운영 모드에는 검토 자산·검토 네트워크 카드가 표시되며 기존 소스 확인 숫자는 표시되지 않는다. 기존 브라우저 검증 도구도 새 집계 순서와 제거 조건으로 갱신했다.
