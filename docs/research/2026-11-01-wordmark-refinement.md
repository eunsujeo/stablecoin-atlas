# 워드마크·사이드바·KPI 정정

사용자가 심벌을 배제하고 이름을 활용한 고급 워드마크를 요청했다. 기존 디자인 브랜치에서 소문자 a와 자산 목록 이니셜을 제거하고 산세리프 Stablecoin/세리프 Atlas의 서체·자간·크기 대비를 적용했다. 접힌 탐색과 모바일에서도 단어를 유지했다. 새 로고 SVG나 이미지·라이브러리·폰트를 취득하지 않았다.

실제 reader 저장 자료를 렌더링해 사이드바와 KPI를 평가했다. 미세한 표면 색조와 가는 구획, 큰 수치와 단위·기준일 분리를 적용했다. 첫 모바일 렌더링에서 단위 줄바꿈 때문에 KPI 하단 정보가 어긋나 동일한 숫자/단위 행 높이로 수정한 뒤 브라우저에서 두 하단 위치 차이 2px 미만을 검사했다. 동작/API/자료/수집/배포 설정은 유지했고 운영 변경은 없다.

검증: `npm run check` rc0 / 879 pass / 0 fail / 기존 compiler 관련 8 skip. Chrome 디자인 브라우저 도구 개발·운영 HTML PASS / JS 오류 0 / 외부 HTTP 요청 0. 워드마크·접힘 저장·메뉴/검색·다크/라이트·360~1600px·popover/focus·오류/빈 상태·로딩을 확인했다. `git diff --check` 통과. 스크린샷과 재현 명령은 [디자인 기록](../design/2026-11-01-interface-renewal.md)을 따른다. 실제 모바일 기기/Safari 검사는 수행하지 않았다.
