# Wallet Flow — Atlas 대시보드 디자인 통일

사용자 요청에 따라 별도 화면처럼 보이던 Wallet Flow를 기존 Atlas 화면 구조에 맞췄다. 새 디자인 시스템이나 라이브러리는 도입하지 않았다.

- 기존 `/styles.css`와 `/pop-outline.css`를 직접 사용한다. 같은 워드마크 SVG, 사이드바 링크/선택 상태, 페이지 헤더, 검색 툴바, segmented 탭, KPI 클래스와 반응형 규칙을 재사용한다.
- 기존 상단 전용 내비게이션을 제거하고 Atlas 좌측 사이드바로 교체했다. 모바일은 대시보드와 동일한 가로 메뉴 구조다. 공개되지 않은 컨트랙트 메뉴는 추가하지 않았다.
- 관측 주소/거래 KPI는 기존 분홍·민트 요약 카드, 나머지는 중립 패널로 표시한다. 숫자와 의미는 유지한다. 다크 모드 중립 카드의 글자색이 공통 강조 카드 규칙에 덮이는 문제를 실제 스크린샷에서 발견해 범위를 한정한 색상 override로 수정했다.
- 테마는 기존 `atlas-theme` 저장값을 읽고 저장한다. 기본 라이트 및 새로고침 유지, 접근성 라벨과 메뉴 aria-current를 제공한다.
- 모델·원문·수집기·공개 snapshot·API·배포 설정 변경 없음. 새 공급자 요청/DB 변경/정기 수집0.

`node --import tsx tools/wallet-flow-browser-check.mjs` rc0/PASS. 실제 관측본3해상도×4뷰와 fixture3해상도×2테마×4뷰, empty/잘못된 TXID/선택/근거 링크/필터/가로 넘침/테마 새로고침 유지/선택 메뉴를 검사했다. 모든 KPI 숫자·보조 라벨의 계산된 대비가4.5:1 이상이다. 기존 테마 transition 도중 찍힌 중간색 캡처는350ms 전환 종료를 기다리도록 검사만 보완했다. 외부 요청0, JS예외0. `.state/wallet-flow-browser/verification.json`과 해당 PNG가 로컬 렌더링 증거다.

`npm run check` 최종 결과와 CI/운영 배포 SHA는 대응 handoff에 기록한다. 기존 사용자 변경3개와 비관련 디자인 자료를 보존했다. 하위 에이전트 사용 없음.
