# 자산 프로필 검색 결과에서 직접 선택

사용자의 작업 시작 지시에 따라 기존 저장 자료를 활용한 화면 사용성을 개선했다. 표시 경계는 [ADR0102](../adr/0102-scoped-top10-profile-excerpts.md)를 유지한다. 새 기술 결정·외부 조사·판정 변경은 없다.

## 수행 경로와 확보 범위

기존 검색은 토큰·네트워크·주소와 일치하는 자산 버튼만 남겼다. 예를 들어 Solana를 검색한 뒤 USDC를 눌러도 이전에 선택한 Ethereum 프로필을 열 수 있었다. 자산별 네트워크 기억은 유지하면서 검색어와 일치하는 개별 프로필 버튼을 추가했다. 각 버튼에는 자산·네트워크·기존 검토 범위를 표시하며 정확한 프로필과 네트워크를 함께 선택한다. 검색 입력이나 지우기 자체는 선택을 변경하지 않는다. 같은 주소가 여러 네트워크에 존재하면 모두 별도 결과로 남긴다.

일치한 프로필 수를 상태 메시지로 제공하고 선택한 결과를 aria-pressed로 표시한다. 기본 버튼의 키보드 동작과 포커스를 유지하며 모바일에서도 검토 범위를 숨기지 않는다. 원래 자산 목록·탭·기능 필터·26프로필·근거 링크·전체 현황/읽기 판정은 그대로 사용한다.

## 실패·원인과 수정

기존 미리보기 포트4397로 새 서버를 시작하지 못해4398에서 이번 작업의 서버를 따로 실행했다. 기존 서버는 종료하지 않았다. 첫 브라우저 검증에서 Enter 합성 이벤트에 입력 문자가 없어 버튼 기본 활성화가 발생하지 않았다. 검사 도구의 Enter keyDown에 carriage return을 전달하도록 수정했다. 제품 버튼에 수동 키 이벤트나 중복 click 처리는 추가하지 않았다.

## 미확인과 재현

화면은 저장 발췌만 검색한다. 검색 결과 수는 지원 체인 수나 기능 성공 수가 아니다. 소스·문서 범위와 기존 미확인은 그대로이며 새 API/RPC/compiler/다운로드·키·DB 변경은 없다. 원문 archive를 읽거나 웹에 게시하지 않았다.

```sh
npm run ui -- --port 4398
node tools/source-review-browser-check.mjs http://127.0.0.1:4398
npm run check
git diff --check
```
