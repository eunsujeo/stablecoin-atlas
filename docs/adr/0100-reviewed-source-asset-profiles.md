# ADR0100: 저장 소스 검토의 자산 프로필 발췌

일자: 2026-10-25. 상태: 사용자 요청으로 구현.

## 결정

사용자가 자산 프로필 업데이트를 요청했다. [최종 소스 검토 요약](../research/2026-10-25-token-review-source-summary.md)의 5토큰·8배포를 기본 웹과 Atlas의 자산 프로필에 공통 정적 컴포넌트로 제공한다. 이 발췌 표시만 기존 기술 검토 CLI의 UI 제외에서 예외다. 웹에서 검증·컴파일·RPC·문서 생성을 실행하지 않는다.

기존 Assessment 보고서 선택·항목·판정·집계는 보존한다. 연구 프로필은 coinId와 명시 chainId/주소로 구성하며 토큰 이름만으로 기존 보고서와 결합하지 않는다. JPYC Ethereum/Polygon/Avalanche/Kaia를 각각 선택할 수 있다. 검토 목록을 지원/실행 인증이나 새 Assessment로 추가하지 않는다.

## 표시와 제공 경계

- 함수·권한 조건, 소스 검토 기준일과 원본 관측 시점/블록, 전체 배포 연결 UNKNOWN, 개별 관측과 한계를 표시한다. USDC runtime 불일치·USDT 조회 실패·JPYC Ethereum 프록시만 일치·타체인 미관측·Kaia 부분 일치·JPYSC 분석 절단을 보존한다.
- 주소·설정은 저장 자료 기준이며 현재 공식 지원·권한·소스 진위·실제 실행을 인증하지 않는다. 원래 SOURCE_REVIEWED·PARTIAL·UNKNOWN·제품 PASS/FAIL은 재판정하지 않는다.
- `web/source-review-data.js`에는 수동 검토한 공개 발췌 필드만 둔다. 원문·RPC URL·키·비공개 경로는 넣지 않는다. 정적 JS/CSS와 공개 발췌 HTML만 고정 허용목록에 추가한다.
- `node tools/source-review-notes.mjs`는 같은 발췌로 로컬 HTML을 생성하는 명시 오프라인 작업이다. 서버 시작/요청은 생성하지 않는다. 정적 파일과 데이터의 동기화는 검사한다.
- 기존 근거 목록 조회 실패와 무관하게 소스 발췌는 선택할 수 있다. 공급자·DB·원본 증거에 대한 새 실행/수정은 없다.

검증·재현은 [작업 기록](../research/2026-10-25-source-review-asset-profiles.md)을 따른다.

## 사용자 요청에 따른 화면 재구성

2026-10-25 사용자의 자산 프로필 재구성 요청으로 기존 정적 발췌를 자산 목록·검색과 배포 네트워크 선택, 개요/기능·권한/근거·한계 탭으로 구성했다. 검색은 저장된 토큰·체인·주소에 한정한다. 자산별 마지막 네트워크를 화면 메모리에 유지하며 다른 자산의 체인을 적용하지 않는다. 기본/Atlas 공통 컴포넌트와 기존 관측 보고서 선택·판정·집계를 유지한다. 추가 취득·상태 판정·데이터 연결은 없다. [재구성·검증 기록](../research/2026-10-25-asset-profile-redesign.md).

## 미확인 항목의 화면 표시 조정

사용자 후속 요청으로 전체 현황의 기술 검증 영역에도 같은 기준을 적용한다. 저장 소스 데이터에서 5자산·4네트워크·8프로필과 기능/권한 조건·SOURCE_REVIEWED·발췌 근거 링크를 표시한다. 기존 읽기 실행 결과/랭킹/점수는 접힌 기록으로 보존하고 산정 정책·분모·원본 판정을 변경하지 않는다. 소스 확인 현황은 읽기 보고서 로드 실패와 독립적으로 표시한다. 웹 요청은 기존 정적 파일만 읽는다.

2026-10-25 사용자 정정에 따라 직접 확인한 범위의 기술 프로필을 제공한다. 상단의 `배포 전체 연결: 미확인 (UNKNOWN)` 배지와 근거 탭의 중복 상태 항목을 제거한다. 소스·저장 관측의 구체적 설명과 한계는 유지하고, 기존 데이터·발췌 문서·연구 보고서의 UNKNOWN과 판정을 변경하지 않는다. 배포 연결 확인을 프로필 작성의 완료조건으로 추가하지 않는다.

사용자는 이어서 소스에서 확인한 기능·권한 조건은 확인한 것으로 처리하도록 명시했다. 프로필의 해당 상태를 `소스 확인 완료`(SOURCE_REVIEWED)로 표시하고 개요에는 소스 확인 범위를 제공한다. 실제 실행·역할 행사·배포 연결을 추가 완료조건으로 요구하지 않는다. 기존 소스와 배포의 대응 설명·실패/불일치는 근거·한계 탭과 발췌 문서에서 보존한다. SOURCE_REVIEWED의 확인 대상은 검토한 소스의 함수·modifier·조건이며 기존 제품 PASS/FAIL이나 배포 동일성 판정을 재판정하지 않는다.

## 전체 현황 요약 표시

사용자 후속 요청으로 전체 현황의 긴 프로필 조건 표를 자산별 5개 요약 카드로 교체한다. 기술 검증 현황은 기본 노출하고, 소스 확인 완료 프로필 수·자산 수·네트워크 수와 기존 저장 읽기 실행 등급을 요약한다. 등급은 기존 SCENARIO_SUCCESS_V1의 잠정 여부·통과 점수·판정 완료 비율을 그대로 사용하며, 소스 확인 완료를 새 A등급이나 PASS로 환산하지 않는다. 상세 조건은 선택한 자산의 프로필로 이동해 확인한다. 실행 원본 집계·정책·실패/UNKNOWN은 변경하지 않는다.
