# ADR0085 저장 자료 기반 로컬 UI 재설계

## 승인과 목적

2026-10-24 사용자가 추천한 가격 표시 설계와 현재 수집 자료에 근거한 전면 UI 재설계를 요청했다. 기존 오프라인 조사 완료 상태에서 로컬 화면 구현을 허용하는 후속 승인이다. 외부 API·비용·키·운영 데이터 변경·공개 배포는 포함하지 않는다.

## 결정

`/atlas.html`에 공급량·전송량·가격·조사 범위를 중심으로 새 로컬 화면을 제공한다. 기존 검토된 공개용 projection과 검증·그래프 모듈만 재사용한다. 수집기·DB·Adapter는 유지한다. 2026-10-24 후속 사용자 승인으로 `/`·`/index.html`을 새 Atlas 화면으로 전환하고 `/atlas.html`을 별칭으로 유지한다. 기존 화면은 `/legacy.html`에 보존하고 기술 검증·보고서·시장 상세 링크를 해당 경로로 연결한다. 기존 화면에는 `/`로 돌아오는 링크를 제공한다. 상세 시각 계획과 가격 필드/단위/누락 계약은 [설계 정본](../ui/ATLAS_REDESIGN.md)을 따른다.

비공개 연구 원문·수치·receipt·주소는 정적 자산이나 새 API에 넣지 않는다. 미승격 표본은 당시 확보 상태와 한계만 표시한다. 통화 UNKNOWN인 가격을 달러·현재가·환산·등락률로 표시하지 않는다. 공급량의 범위와 전송량의 정의를 분리한다. 금액 문자열·기존 판정·시각·누락을 보존한다. 웹 시작·조회·새로 읽기는 외부 수집·파일 생성·DB 쓰기를 실행하지 않는다.

## 검증

고정 자산 allowlist·loopback·CSP 경계를 유지한다. 새 UI의 기존 projection 해석, 누락/실패/이전 정상 자료 보존, 필터/기간/정렬, 테마·모바일·키보드와 외부 요청0을 점검하고 `npm run check`를 실행한다. 실제 결과는 이번 인계문에 기록한다.

## 자산별 근거 탐색 후속 승인

2026-10-24 사용자가 추천한 자산 프로필·비교 연결을 기획 후 계속 진행하도록 승인했다. 조사 범위 상단에 두 화면의 설명이 있는 진입점을 두고 기술 검증·보고서 링크를 함께 제공한다. 기존 근거 화면에는 `/#coverage`로 돌아오는 링크를 추가한다. 상세 구성은 설계 정본을 따르며, 새 자료 입력·집계·공급자 요청 없이 기존 화면과 공개용 근거를 재사용한다.

## Atlas 내부 프로필·비교

사용자의 연속 진행·남은 작업 정리 요청에 따라 자산 프로필·비교를 Atlas 내부에서도 표시한다. 기존 공개용 근거 index와 evidence-model을 재사용하고 STORED_READ_ONLY만 선택/표시한다. 체인 식별과 판정·지원·실행, 원래 관측/완료시각을 보존한다. 새 DTO·endpoint·parser·집계·DB/공급자 연결은 없으며 근거 읽기 오류는 시장 읽기와 격리한다. 선택 삭제는 명시하고 실패 시 마지막 정상 자료와 유효 선택을 보존한다. 기존 문서와 legacy 화면을 유지한다. 상세 구성과 남은 작업은 설계 정본을 따른다.
