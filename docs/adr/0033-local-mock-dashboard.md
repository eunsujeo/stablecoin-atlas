# ADR0033: 확정 디자인의 로컬 목데이터 웹 대시보드

- 상태: 사용자 승인 후 채택, 2026-10-21
- 배경: 사용자가 다크·라이트 시안을 확정하고 다음 구현을 요청했다. 저장 데이터의 조회 화면을 먼저 확인한 뒤 수집·DB·API를 연결한다.

## 결정

`web`의 HTML·CSS·JavaScript와 Node 내장 HTTP 서버로 로컬 미리보기를 구성한다. 추가 패키지나 프레임워크를 설치하지 않고 확정 시안의 배치·색상·그래프를 유지한다. Ant Design·MUI·Material 3 도입을 확정하는 결정은 아니다.

자료는 `docs/ui/mock-dashboard-data.json` 하나다. 가상 자료 표식을 검증하고 화면·차트·툴팁·상세·등급에 예시임을 표시한다. 수량은 정규 십진 문자열과 BigInt로 합산·정렬한다. 차트 좌표에만 제한된 정수 비율을 Number로 변환한다. 축과 요약은 축약 표시이며 상세와 툴팁에는 정확한 원본 수량을 제공한다.

코인 전체 3개와 선택한 자산·체인 8개는 분리된 범위다. 필터와 전환 시 합계·비율의 분모·범위 라벨을 함께 갱신한다. 체인별 과거 자료는 제공되지 않았으므로 추이를 생성하지 않는다. 점수와 등급은 수작업 목데이터이며 실제 보고서나 산정 기준과 연결되어 있지 않다.

서버는 127.0.0.1에만 바인딩하고 실제 포트에 맞는 Host·Origin을 검사한다. GET/HEAD로 고정 경로만 제공하며 저장소 전체·환경변수·임의 URL·경로는 제공하지 않는다. CSP·nosniff·no-store를 적용하고 외부 스크립트·폰트·연결을 추가하지 않는다. 모달은 키보드 닫기와 포커스 복귀를 지원한다.

## 실행과 범위

`npm run ui`로 시작하고 출력된 로컬 주소를 연다. 기본 포트는 4173이며 `npm run ui -- --port 0`은 사용 가능한 포트를 선택한다. 실행한 터미널에서 Ctrl+C로 종료한다.

실제 수집·DB·외부 API·실제 등급 산정·60초 자동 조회·공개 배포는 후속 단계다. 다시 읽기는 같은 로컬 목데이터만 읽으며 화면 읽음 시각과 가상 자료 시각을 구분한다. 오류 시 마지막 성공 자료와 읽음 시각을 보존한다. 실제 CLI·Adapter와 기존 증거를 변경하지 않는다.

터미널 스타일은 웹 테마를 뜻하며 Ink·TTY 구현은 이 결정에 포함하지 않는다.

## 검증

정밀 금액·범위 합계·정렬·잘못된 목데이터·명시적 0과 미확인 구분, 서버의 고정 경로·Host·Origin·HEAD·경로 탈출 거부를 자동 검사한다. 실제 브라우저에서는 테마와 저장된 선택, 필터·검색·정렬, 정확한 툴팁, 체인별 상세, 모달 닫기와 포커스 복귀, 좁은 화면, 오류 후 이전 값 보존을 확인한다. 전체 검사는 `npm run check`다.
