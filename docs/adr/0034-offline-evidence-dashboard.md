# ADR0034: 로컬 검증 근거 보존과 항목별 대시보드

- 상태: 사용자 승인 후 채택, 2026-10-21
- 배경: 사용자가 로컬 검증을 근거 문서로 남기고 항목별 현황, 자산 프로필, 자산 비교를 대시보드에서 확인하도록 요청했다.

## 결정

`npm run evidence:build`가 고정 입력 목록을 오프라인으로 읽고 기존 AssessmentReport 검증기로 형식과 내부 일관성을 검사한다. 실제 자산의 저장된 읽기와 사설 Anvil Fixture의 실행 결과를 구분한다. 입력 파일 수·크기·깊이를 제한하고 regular-file/O_NOFOLLOW/O_NONBLOCK 읽기를 사용한다. 외부 요청과 거래는 실행하지 않는다.

입력은 한 번 읽은 바이트로 해시·검증·추출한다. Lab envelope는 고정 Fixture 목록과 사설 네트워크·모드를 확인한 뒤 내장 AssessmentReport를 검사한다. envelope 전체가 인증되었다고 하지 않는다. 부모 입력 바이트 해시, 내장 보고서 선택 위치와 재직렬화 해시를 구분해 기록한다.

원본 입력은 `reports/dashboard-evidence/sources`에 보존한다. 항목 키에는 보고서 내용 해시·assessmentId·scenarioId·capability가 포함되어 다른 실행이 같은 시나리오를 덮어쓰지 않는다. 생성 문서와 발췌 JSON은 각각 내용 해시로 보존한다. 이전 실행을 유지하고 최대 한도에 도달하면 조용히 삭제하지 않고 생성을 중단한다.

모든 산출물을 준비한 뒤 인덱스를 마지막에 원자적으로 교체한다. 생성 실패 시 이전 인덱스를 유지하고 별도 실패 상태를 기록한다. 새 파일은 0600, 디렉터리는 0700으로 생성한다. 원본의 시작·완료·관측 시각은 문서 생성 시각과 구분한다.

## 웹 조회

기본 화면은 실제 저장된 자산 읽기의 항목표다. 범위 필터에서 로컬 Fixture와 전체 자료를 선택할 수 있다. 판정·지원·실행 상태를 따로 표시하고 관측값·제약·참조 evidence·원본 연결 해시를 상세에서 확인한다. 자산 프로필에는 식별자와 항목표, 비교에는 동일 범위의 2~3개 실행별 시나리오를 표시한다. 체인별 승인·위임·인가를 같은 동작으로 취급하지 않으며 미수록 항목을 미지원으로 추정하지 않는다.

웹은 고정 인덱스와 그 인덱스에 포함된 보고서 ID만 읽는다. 원본 스냅샷은 웹 경로에 포함하지 않는다. 허용 필드와 크기 제한을 적용한 발췌 JSON 및 읽기용 HTML 문서만 제공하고 응답 전 내용 해시를 확인한다. 비밀정보 필드·URL 포함 입력을 게시하지 않으며 HTML은 이스케이프하고 화면은 textContent로 표시한다. 기존 loopback·Host·Origin·CSP·GET/HEAD 경계를 유지한다.

공급량 목데이터는 Market preview로 분리한다. 이 화면의 수치·등급은 검증 근거로 사용하지 않는다. 소스 검토와 직접 연구 자료를 공통 AssessmentReport의 PASS로 변환하지 않는다. 지원하지 않는 연구 형식은 이 문서 생성기에 넣지 않는다.

## 로컬 작업 순서

1. `npm run lab -- --out reports/dashboard-local-validation.json`으로 신규 사설 Anvil Fixture를 실행한다. 의도된 실패 Fixture의 결과가 FAIL이면 CLI 종료 코드 2가 될 수 있다. 인프라 오류·자동 테스트 실패와 구분한다.
2. `npm run evidence:build`로 검사한 근거 문서·발췌본·인덱스를 보존한다. 실제 자산 읽기는 고정 목록의 기존 보고서를 사용하며 이 명령은 공개망을 재조회하지 않는다.
3. `npm run ui`로 로컬 화면을 열고 근거 다시 읽기로 인덱스를 읽는다. 서버 종료는 실행 터미널에서 Ctrl+C다.

## 검증

원본 바이트 보존, 해시 연결과 변경 거부, 서로 다른 실행 보존, 누락·비밀 필드·잘못된 보고서, 중간 생성 실패 시 이전 인덱스 유지, HTTP 원본 노출 거부를 검사한다. 실제 브라우저에서는 항목 필터·상세·문서, 자산 식별자와 프로필, 2~3개 비교와 중복 선택 거부, 테마·모바일을 확인한다. 전체 검사는 `npm run check`다. 해시와 형식 검사 통과는 진위·재현·자산 안전성 인증이 아니다.
