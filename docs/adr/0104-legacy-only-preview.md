# ADR0104: 기존 UI 단일 제공과 메뉴 정리

일자: 2026-10-25. 상태: 사용자 승인·구현.

## 결정

사용자 요청에 따라 기존 UI만 제공한다. `/`를 기본 경로로 사용하고 `/index.html`은 같은 화면을 제공한다. `/legacy.html`은 query를 보존하여 `/`로308이동하며 브라우저 hash도 유지한다. `/atlas.html`과 Atlas 전용 CSS·모듈·대시보드는 삭제한다. 제거한 파일 URL은 GET/HEAD 모두404다. 기존 화면에서 Atlas로 이동하는 링크도 제거한다.

사용자 후속 요청에 따라 검증 근거(`#validation`)와 자산 비교(`#compare`) 메뉴·페이지·전용 브라우저 모듈/스타일을 제거한다. 예전 hash로 진입하면 기존 알 수 없는 경로 처리에 따라 전체 현황을 표시한다. 전체 현황의 삭제 페이지 링크와 판정/랭킹의 항목별 이동 동작도 제거한다. 저장 보고서 이동은 보고서 페이지를 사용한다. 자산 프로필·전체 현황·시장 화면·보고서와 원본 소스·관측·판정은 보존한다.

과거 ADR·연구 기록은 당시 구현 기록으로 보존하며 현재 제공 범위는 이 결정을 따른다. 새 외부 조회·RPC·compiler·키·DB 변경은 없다. 수행·검증은 [작업 기록](../research/2026-10-25-legacy-only-preview.md)을 따른다.
