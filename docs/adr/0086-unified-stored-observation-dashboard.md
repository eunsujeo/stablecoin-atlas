# ADR0086 공통 조건의 저장 관측 대시보드

## 목적과 범위

2026-10-24 사용자가 수집→저장→조회→KPI·차트·표를 연결하는 대시보드를 요청했다. 기존 스테이블코인 프로젝트와 승인된 수집 경로를 재사용한다. 기존 외부 단발 예산·재시도0·비공개 자료 경계는 유지하며 이번 실행의 새 외부 데이터 호출·반복 예약·DB 연결/변경·키 제공·공개 배포는 없다. 실제 저장 관측을 사용하며 가상 자료로 빈 화면을 채우지 않는다.

## 결정

`/market-data.json`의 검증된 기존 projection을 공통 모델 `web/atlas-dashboard-model.js`에 전달한다. 코인·지표·체인·기간·정렬·페이지는 URL에 저장하고 KPI·추이·상세 표가 동일한 조건을 쓴다. 뒤로가기와 새로고침으로 복원한다. 체인 필터는 CHAIN_TOTAL에만 적용하며 전체 코인 유통량/가격에 적용하지 않는다. 여러 계열을 합산하지 않고 개별 비교로 표시한다. 기존 전송량·가격·연구·프로필·비교 화면과 legacy 링크는 유지한다. 전송량의 비활성 경로를 새 수집이나 가상 값으로 대체하지 않는다.

계열 키는 coin·deployment·metric·unit·provider·endpoint·selector 전부다. 같은 키/동시각의 중복은 ID 내림차순 우선으로 결정한다. 이전 selector 계열을 새 selector 계열에 이어 붙이지 않는다. 표시할 기간의 끝은 선택 계열들의 마지막 저장 관측으로 고정하고, 관측 기록 `observedAt`과 데이터 기준 `sourceAt`을 구분한다. sourceAt 부재는 미제공이며 조회/수집 시각으로 채우지 않는다. 읽기 제한 밖 자료를 보충하지 않는다.

금액·차이·변화율 계산과 수량 정렬은 bigint·십진 문자열을 사용한다. Number는 날짜·화면 좌표·정규화한 그래프 비율에만 쓴다. 이전 동기간은 같은 길이의 앞 구간이며 경계 근접성과 공백 검사를 통과한 단일 계열에서만 마지막 관측끼리 비교한다. 전체 기간 선택·표본화·최근 실패/누락·실패 발행·이전 구간 부족·0 분모는 변화율 미표시다. 실제 관측 구간의 첫 값 대비 변화와 이전 동기간 대비를 별도 표시한다. 증감률은 소수 둘째 자리까지 절삭하며 경제적 정확성 인증이 아니다.

30분 초과 간격은 표시 정책으로 선을 끊는다. 이는 수집 완전성 인증이나 실제 운영 주기가 아니다. 계열마다 공백을 분리한 뒤 구간별 최대240개 첫/끝·버킷 극값을 그린다. KPI·정렬/페이지 표·변화 계산은 축약 전 관측을 사용한다. 본래 JSON 최대5000관측·2MiB 제한을 유지하며 기존 DB 읽기의 sampled 상태를 보존한다. 큰 조회의 서버 측 축약은 기존 DB 경로를 재사용한다.

조회 실패·404·잘못된 DTO는 마지막 정상 자료·시각·필터를 유지한다. 최초 빈 저장소·조건 결과 없음·조회 실패·갱신 중·부분 관측·수집 실패·오래된 자료를 구분한다. 24시간 경과는 화면의 저장본 경고 기준이며 예정된 수집 SLA가 아니다. 수집 상태는 기존 collection/scheduler 기록에서 읽고 오류가 HTTP 코드만 있으면 그 범위만 표시한다. 저장 완료시각을 데이터 기준시각으로 승격하지 않는다.

## 수집과 보존

실제 수집 기능은 [ADR0037](0037-manual-market-collector.md)과 `tools/market-collect.mjs`, 정규화/원자적 발행/동일 입력 재사용은 `tools/market-store.mjs`를 재사용한다. 승인된 단발7GET·1초 간격·요청15초·전체120초·응답2MiB·재시도0·추가페이지0은 그대로다. 실패/429는 다음 자동 시도로 이어지지 않는다. API key는 서버 환경에만 존재한다. 원격 전체 응답 대신 허용 필드 projection을0600으로 보존하며 top holders/기관/지갑 정보는 저장·공개하지 않는다. 보존 projection의 hash는 전체 원격 원문의 hash라는 뜻이 아니다.

새 필드·공급자·증분 cursor·페이지네이션·자동 재시도를 이번 작업으로 활성화하지 않는다. 기존 자료 재입력은 같은 관측 ID로 중복 제거되며 새 요청시각의 관측은 새 이력이다. 웹의 다시 읽기와 서버 시작은 공급자를 호출하지 않는다. 연구 원문은 별도 비공개 보관소에 유지하며 UI 정규화에 추가하지 않는다.

## 디자인과 검증

시각 계획·참고 페이지와 실행 방법은 [대시보드 안내](../ATLAS_DASHBOARD.md)를 따른다. 출처명/출처 열/원문 hash는 대시보드에서 제외하고 metadata·근거 문서는 유지한다. 동일 조건·정밀도·0분모·중복·정렬 후 pagination·계열 분리·공백·URL 복원·키보드 선택·오류 후 마지막 정상값·두 테마·390px와 외부 요청0을 검증한다. 실제 명령과 결과는 이번 인계문에 기록한다.
