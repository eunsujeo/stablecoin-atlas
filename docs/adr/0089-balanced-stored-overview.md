# ADR0089: 전체 현황의 카드 균형과 전송량 구성비

- 상태: 사용자 승인, 2026-10-24. 사용자가 제공한 CRM 대시보드를 전체 페이지의 배치·밀도 참고로 사용한다.
- [ADR0088](0088-yearly-token-network-overview.md)의 읽기 경로와 판정 경계를 유지하고 화면 배치를 대체한다. 새 수집·API·키·DB 변경은 없다.

## 페이지 구성

공통 USD/JPY·단일 토큰 선택 아래에 실제 관측 수치 카드2개를 배치한다. 중단은 공급량 추이와 네트워크 순위, 하단은 전송량 추이와 도넛이다. 같은 열 폭·간격·행 높이를 사용하고 긴 공급량 순위는 카드 안에서 스크롤한다. 최대 본문 폭과 머리글·기술 근거 영역을 정렬하며 다크/라이트와 모바일의 세로 배치를 유지한다. 예시의 CRM 수치·점수·색상 의미를 데이터로 가져오지 않는다.

수치 카드는 표시 네트워크 중 최신 관측 공급량 최대와 선택 집계일의 표시 네트워크 중 전송량 최대다. 토큰 단위·네트워크·각 기준일과 이전 정상 자료 상태를 표시한다. 공급량은 네트워크별 관측일이 다를 수 있다. 네트워크 공급량을 합산해 코인 전체 공급량으로 만들지 않는다. 공급량1Y/3M/30D·증감률과 전송량7D는 분리한다.

후속 사용자 요청으로 사이드바는 전체 현황·자산 프로필·자산 비교·검증 근거의4개 메뉴로 정리했다. 중복 시장/분석 링크, 목데이터 미리보기, 고정3자산 바로가기와 개발 안내/중복 근거 버튼을 제거했다. 기존 화면·문서 경로와 데이터는 변경하지 않는다.

## 전송량 도넛의 범위

같은 토큰·source hash·query 시각·window·명시된 PROVIDER_DAY의 non-null 관측만 구성비 후보로 사용한다. dateBasis를 추정 기본값으로 만들지 않으며 집계 시간대 UNKNOWN을 보존한다. 중복 네트워크·중복 날짜·혼합 source/window/token은 거절한다. 도넛의 분모는 선택 날짜의 표시 중인 네트워크 전송량이며 시장 전체나 고유 결제액의 비중이 아니다. 화면에는 `표시 네트워크의 관측 전송량`과 선택 날짜를 표시한다.

금액 비교·합계·비중 계산은 bigint이며 원래 수량은 십진 문자열로 유지한다. 비중 표시만 소수 둘째 자리 반올림하고 SVG 좌표는 제한된 수치로 변환한다. 반올림 비중 합계는100%와 다를 수 있다. 실제0합계는0 tokens와 미산정 비중, 전체 숨김은 선택 필요, 선택일 결측은 관측 없음으로 구분한다. 미관측·숨김을0으로 만들거나 다른 날짜의 값을 가져오지 않는다. 네트워크1개인 경우에도 원래 수량을 도넛 중앙에 표시한다.

전송량 차트의 포인터·키보드 날짜 선택은 도넛과 해당 수치 카드만 갱신한다. 추이 DOM과 키보드 초점을 유지한다. 선택일은 필터·기간·토큰·출처 전환에서 보존하며 새로운 자료에 없으면 결측으로 표시한다. `최근일` 버튼이나 실제 관측점 선택만 날짜를 바꾼다. 최초 선택은 데이터에 있는 마지막 날짜이며 현재 시각을 사용하지 않는다. 이전 차트의 늦은 콜백은 연결된 현재 카드만 갱신한다.
