# ADR0043: 자산·네트워크별 검증 랭킹

상태: 채택. 2026-10-22 Overview 정정과 사용자 UI push 지시를 반영했다. Lead 전달 미확인 기록은 인계문에 보존하며, 명시 push 지시에 따라 공유한다.

## 집계와 표시

Overview의 주 랭킹은 자산별·네트워크별 통과 점수/판정 완료 비율이다. [ADR0038](0038-overview-scenario-results.md)의 SCENARIO_SUCCESS_V1 공식을 유지한다. 자산은 저장된 asset명별로 체인 근거를 합산하고, 네트워크는 chain+networkId로 나눈다. 사용자 후속 정정에 따라 대시보드는 실제 자산의 저장된 조회 결과만 집계한다. 개발용 Fixture는 Overview·검증 목록·자산 프로필·비교·보고서 목록에 표시하지 않는다.

같은 자산/체인/네트워크/계약·mint·issuer/currency 식별자의 최신 보고서를 먼저 고른다. asset 또는 networkId가 없으면 같은 실행이라고 추정하지 않고 보고서별로 보존한다. 그룹의 PASS/FAIL/비적용 등 항목 수를 합산한 뒤 비율을 계산하며 보고서별 백분율을 평균하지 않는다. 자산별로 네트워크/보고서 수, 모든 행에 점수와 확정 판정 분모·완료율과 대상 분모를 표시한다.

정렬은 통과 점수/판정 완료 비율 중 선택한다. 반올림 전 정수 교차곱으로 비교하며 동점은 공동 순위(1,1,3)다. 선택 지표의 분모가 없으면 미산정·순위 없음으로 뒤에 배치한다. 판정이 모두 미확인이면 점수는 미산정이고 완료율0%는 유효하다. 해당 행을 누르면 그룹의 최신 보고서 항목 전체로 이동한다.

개발용 Fixture의 원본 보고서·내부 LOCAL_FIXTURE 코드·CLI/자동 검사는 보존한다. 화면용 index를 실제 자산 범위로 파생하며 원본을 삭제하거나 판정을 변경하지 않는다. 웹 요청의 저장 index 재독은 검사 실행과 별개다.

시장 화면의 코인 선택은 요약/그래프 위에 두고 USDC/USDT/RLUSD를 선택할 수 있게 한다. “저장된 공급자 관측”은 “수집한 시장 데이터 · 출처: Arkham”으로 설명한다.

시장 유통량/총공급량은 하단 별도 참고 지표로 유지한다. 검증 점수와 혼합하지 않는다. 체인/시나리오 구성이 다르므로 이 순위를 자산 안전성·신용·공식 지원 또는 네트워크의 우수성 인증으로 해석하지 않는다.

## 검증

모델 검사에서 개발용 토큰의 UI 제외와 원본 보존·항목 가중 집계·최신 실행 제외·범위 분리·정확한 비율 동점·표시값만 같은 비동점·0/미산정·누락 식별자 분리를 검사한다. 실제 저장 근거의3자산/4네트워크·8보고서/111항목·정렬 전환·그룹31항목 이동·프로필/비교/보고서의 개발 자료 제외·상단 코인 선택·다크/라이트/모바일은 브라우저에서 확인한다. 개발 검토 요청 상태와 최종 검사 결과는 인계문에 기록한다.

사용자 후속 정정: 일반 이용자의 첫 화면은 유통량 추이와 네트워크별 공급량·시장 랭킹을 중심으로 한다. 기술 검증은 개발자·전문가용 영역으로 구분해 Overview에서는 기본 접힌 보조 영역에 두며, 기존 Validation/프로필/보고서 상세를 유지한다. 접힌 기술 요약 첫 두 카드는 검토한 자산 수·체인과 네트워크 ID로 구분한 네트워크 수이며, 판정 완료 비율·통과 점수는 뒤에 둔다. 수는 최신 조회 보고서의 실제 식별 정보에서 계산하고 자산·네트워크 프로필 수도 별도 표시한다. 등록 수나 검증 완료/취급 승인 수로 바꾸지 않는다.

Overview 그래프는 저장된 CIRCULATING 관측과 같은 차트 모듈을 사용하고 코인·24H/7D/30D 선택을 제공한다. 네트워크 비교는 동일 요청 그룹의 CHAIN_TOTAL이며 코인 전체 유통량과 합산하지 않는다. 거래량은 정의 확인 전, 기간 중 발행·소각은 별도 수집 전 미확보다. COIN_TOTAL 패널은 현재 총공급량으로 명명하고 신규 발행 흐름으로 해석하지 않는다. 그래프를 여러 화면에 함께 두므로 SVG gradient ID는 host별로 분리한다.
