# ADR0087: Legacy UI의 Allium 관측값 중심 현황

- 상태: 사용자 승인, 2026-10-24
- 사용자 지시: legacy UI 유지, Allium으로 구성, 미확보 자료 제거와 있는 데이터만 표시.

## 결정

Overview의 시장 영역을 기존 테마·패널·표 스타일을 사용하는 Allium 전용 현황으로 구성한다. 기존 시장·등록 공급량·조사 상태 표는 이 현황에서 숨기며 기존 모듈과 별도 시장/기술 근거 경로는 보존한다. 신규 기본 공급자 수집 전환이나 기존 저장 자료의 변경은 아니다.

기존 검토된 ALLIUM_STORED_SURVEY DTO만 사용한다. 같은 window의 종류별 snapshot을 유지하고 코인·공급량 지표·전송 지표·차트 네트워크를 선택한다. 공급량은 total/circulating/adjusted를 구분하며 tokens로 표시한다. 전송량/전송 건수/트랜잭션 수는 별도 지표다. 체인별 마지막 관측값마다 실제 기준일을 표시하고 체인 합을 전체 유통량으로 만들지 않는다. 체인을 누르면 해당 코인·체인의 일별 이력을 native dialog에서 표시한다.

OBSERVED 행의 non-null 값만 화면 점과 표를 만든다. 실제 0은 유지한다. 해당 필드가 없는 코인/체인/지표와 종류 전체는 숨긴다. 누락 날짜는 선을 끊고 보간하지 않는다. 원래 DTO의 null/MISSING/INCONCLUSIVE와 원본 판정은 변경하지 않는다. 읽기 실패는 이전 정상값과 실패 상태를 표시한다. 유효한 빈 자료나 미연결이면 데이터 패널을 숨긴다. 상세와 표의 수량은 원래 십진 문자열, SVG 좌표만 bigint 비율의 제한된 근삿값이다.

집계일과 종류별 queriedAt을 분리하며 집계 시간대 UNKNOWN과 최소 단위 정밀도 미검증을 유지한다. 발행·소각·가격·지리·보유자 카드와 자료 미확보 표시는 만들지 않는다. 저장 supply_change는 완료 미확인이고 공급량 차이를 발행량/소각량으로 분해하지 않는다.

## 로컬 저장본 연결

기존 DB 읽기 모드의 surveyReader를 재사용한다. 외부 DB 접속 없이 보려면 `npm run ui -- --survey-file PRIVATE_REVIEWED_SURVEY_DTO.json`으로 검토된 공개용 projection을 명시한다. DB 모드와 동시 지정은 거부한다. 파일을 boundedRead(128KiB, 일반파일·symlink 거부)하고 기존 validator로 허용 필드만 재구성한다. 파일 경로나 원문/SQL/실행 ID는 웹 응답에 추가하지 않는다. 파일을 생성·변환하거나 공급자를 호출하는 동작은 웹/서버 시작에 없다. 잘못된 파일은 503이며 다른 소스로 전환하지 않는다.

이번 로컬 연결은 기존 오프라인 검토를 새 별도 결과 파일로 재실행하여 274관측·42입력 불변·차이0을 확인한 후, 당시 DB 조회 projection의 hash를 대조해 별도 비공개 .state 파일에 보존했다. 최신 snapshot은 공급량70/전송량67관측이며 2026-10-16~22의 과거 자료다. 원문/기존 검토·판정·시각은 보존한다. 새 공급자/API/키/DB 접속·변경은 없다.

## 검증

정밀도/실제0/null/미일치/누락 종류·날짜 공백·종류별 시각과 로컬 파일 경계는 자동 시험으로 검증한다. 실제 저장본의 코인 전환·일별 상세·Escape/포커스·503 이전값·404 숨김/복구·두 테마·390px·외부0·런타임오류0을 브라우저에서 확인한다. 최종 명령과 결과는 인계문에 기록한다.
