# ADR0038: Overview 종합 결과와 지표별 순위

상태: 채택. 사용자 Overview 결과·점수/등급·유통량/거래량/발행량 순위 요청(2026-10-22).

## 결정

기본 경로와 `#overview`는 종합 화면이다. 기존 항목 목록은 `#validation` 직접 링크와 별도 메뉴로 보존한다. 기존 보라·청록 카드 테마를 사용한다. 웹은 검증된 로컬 index와 시장 projection만 읽으며60초 재독·명시적 새로 읽기 모두 외부 API를 호출하지 않는다. 읽기 실패 시 이전 정상 자료의 시각을 유지하고 실패를 표시한다.

점수 정책은 `SCENARIO_SUCCESS_V1`이다. **확정 판정 중 시나리오 통과 비율**이며 자산 안전성·신용도·지원 여부·취급 승인 등급이 아니다.

- 점수: PASS / (PASS + FAIL) × 100, 표시만 소수점 버림.
- 판정 완료 비율: (PASS + FAIL) / (전체 항목 - NOT_APPLICABLE) × 100.
- 등급: 정확한 비율로 A≥90, B≥80, C≥70, D≥60, F<60. 미확정 항목이 남으면 잠정 표시.
- P+F가 없으면 점수/등급 없음. 전부 비적용이면 완료 비율도 없음.
- INCONCLUSIVE/NOT_TESTED/UNSUPPORTED 및 실행 ERROR/NOT_EXECUTED를 별도 표시한다. SOURCE_REVIEWED/연구 관측을 PASS로 가산하지 않는다.
- 실제 자산의 저장 읽기와 사설 Fixture를 별도 선택·집계한다. Fixture의 원시 FAIL은 예상 음성일 수 있으며 자동 테스트 실패나 품질 점수로 바꾸지 않는다.

같은 자산/체인/네트워크/계약·mint·issuer/currency 식별자의 최신 보고서 한 개를 집계한다. 동일 완료 시각은 보고서 hash 순서로 결정한다. 선택 보고서·원본 완료 시각·문서 링크를 공개한다. 서로 다른 시나리오 버전/체인의 구성을 같은 품질로 인증하지 않으며 코인별 안전성 순위도 만들지 않는다. 항목 검색/필터는 Overview 집계 분모를 바꾸지 않는다. 결과 건수에서 항목 목록으로 이동할 때만 해당 범위/판정 필터를 적용한다.

## 시장 지표

유통량 `CIRCULATING`과 코인 전체 공급자 총공급량 `COIN_TOTAL`은 각각 정밀 십진 문자열/BigInt로 정렬한다. 총발행량이라는 UI 제목은 **현재 totalSupply**이며 기간 중 민팅/소각량이 아니다. 체인별 총공급량이나 XRPL obligations를 코인 전체 지표에 합산·차감하지 않는다. 누락은0이 아니며 각 행에 관측 시각과 미확보 범위를 표시한다.

`market.totalVolume`은 선택 필드로 projection·출처 hash/selector/시각을 보존하되 metric `REPORTED_VOLUME`, unit `UNKNOWN`이다. 공식 상세 문서 접근으로 기간/단위를 확인하지 못했으므로 거래량 랭킹은 비교 기준 확인 중으로 표시한다. 이 값을 USD/24h로 추정하거나 가격과 곱하지 않는다. `/token/volume`의 과거400을 반복 호출하지 않는다.

기존7회 단발 수집의 필드만 확장한다. 자동 수집/추가 endpoint는 도입하지 않는다. 이번 화면 자료 보강은 보존된5개 입력의 오프라인 재정규화이며 새 외부 관측이 아니다. 이전 과거 값에는 기존 관측 시각을 유지한다.

## 검증

점수/coverage/미확정/전체NA/등급 경계/범위 분리/음성FAIL·최신 실행 선정, 서로 다른 공급량 순위, 숫자 정밀도·명시적0·optional 누락·거래량 비교 거부를 검사한다. Chrome 기본 경로와 직접 링크·범위/판정 이동·다크/라이트·390px·읽기 실패 유지 및 외부 요청0건을 확인한다. 구체적인 실행 결과는 인계문에 기록한다.
