# ADR0133 — 재접속 시 최신 자료 우선 표시

2026-11-07 사용자가 오랜만에 접속하면 이전 자료가 먼저 보여 고장처럼 느껴진다고 보고했다.

## 결정

기존 API별 TTL과 검증된 IndexedDB 저장본을 유지한다. 제품의 cachedJSON은 TTL이 지난 저장본을 즉시 반환하지 않고 최신 요청을 기다린다. 실패할 때만 검증된 마지막 정상 자료를 원래 관측시각과 갱신 실패 안내와 함께 반환한다. 취소·캐시 삭제 후에는 이전 자료를 복원하지 않는다. 429 cooldown은 강제 조회로도 우회하지 않는다.

전체 현황과 시장 화면의 수동 다시 읽기는 TTL을 우회해 서버를 확인한다. 1분 이상 지난 뒤 탭 복귀·focus·BFCache 복원·화면 재진입 시에도 확인한다. 연속 복귀 이벤트를 합치고 진행 중 요청은 중복 시작하지 않는다. 이미 표시된 화면은 확인 중임을 명시하며 유지한다. 최초 진입은 기존 로딩 UI를 사용한다.

요청 동시성2·간격250ms·대기32·동일 요청 병합·자동 재시도0·검증/해시/원래 날짜는 유지한다. 공급자 API 호출, 수집 일정, DB 스키마 및 자료 변경은 없다. 유효 TTL 내 일반 진입은 정상 캐시를 계속 사용하므로 매 접속마다 모든 API를 강제 호출하지 않는다.

## 검증

캐시 단위 테스트: 만료 응답 대기, 실패 시 last-good, 수동 강제 조회 병합, 취소·삭제, 복귀 이벤트 중복 방지. Chrome 실제 렌더링: 1440×900·390×844에서 식별 가능한 과거 가격을 로컬 격리 fixture로 저장한 뒤 8일 경과를 재현한다. 지연 응답 중 과거 가격 미노출, 최신 응답 표시, 수동 갱신과 복귀 요청 각각1회, 서버503 이후 안내가 있는 이전 자료, 자동 재시도0을 확인한다. 운영 응답과 저장 자료를 변조하지 않는다.
