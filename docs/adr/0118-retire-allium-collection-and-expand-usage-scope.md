# ADR0118: Allium 수집 종료와 전체 등록 활동 범위 준비

- 날짜: 2026-10-28
- 상태: 오프라인 구현. 신규 Arkham 실행 승인 대기.

## 결정

사용자 요청에 따라 Allium 신규 수집은 종료한다. 실제 실행 CLI/npm 별명과 workspace 키 전달을 제거하고 일반 프로세스의 직접 수집 모듈 호출도 거절한다. 기존 불변 DB/원문/소비·파서·오프라인 계획/저장본 읽기는 유지한다. Arkham도 사용하는 기존 공통 파일/잠금 모듈의 이름만으로 이를 삭제하지 않는다.

과거 수집기의 원장·에러·한도 회귀를 보존하되, 일반 테스트와 네트워크 권한 없는 Node permission 테스트 프로세스를 분리한다. 고정/가상 응답을 주입하는 회귀 7개 파일은 파일·자식 프로세스 권한만 허용한다. 실제 socket 사용을 거절하며 자식에 같은 NODE_OPTIONS를 상속한다. 함수 동일성 비교만으로 fetch wrapper를 안전하게 구분할 수 없으므로 net 권한이 있는 프로세스에서는 모든 transport를 거절한다. Node v25.2.1에서 확인했고 permission 기능 부재는 허용으로 처리하지 않는다. 전체 파일/자식 권한이 있는 신뢰한 회귀 환경이며 임의 악성 코드 격리나 조직 비용 통제를 주장하지 않는다.

활동 자료 수집 대상은 시장 등록 coverage 33쌍이다. 기존 승인된 5쌍/35관측은 재수집하지 않고, 28쌍을 미수집으로 구분한다. 지원 여부·chain alias·정확한 token identity가 미확인인 조합에 값을 채우지 않는다. 가격 ID와 토큰 주소, 기존 소스 검토와 현행 공급자 지원을 구분한다.

새 외부 실행의 다음 단위는 별도 discovery 슬롯의 정확한 메타데이터4GET 계획이다. 사용자 고정 승인을 받기 전에는 실행하지 않는다. 결과 후 histogram 목록과 실제 DB 확장/적용을 각각 고정한다. 기존 schemaVersion1/35행 저장 형식과 원본은 이번에 변경하지 않는다. Collector·FX·운영 배포는 제외한다.
