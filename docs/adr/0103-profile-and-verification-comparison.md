# ADR0103: 자산 프로필 비교와 저장 검증 비교

일자: 2026-10-25. 상태: 사용자 ‘자산비교’·‘검증 비교’ 정리 요청으로 구현.

## 결정

기본/Atlas의 기존 `#compare` 안에 두 보기를 둔다. 기본 ‘자산 비교’는 [ADR0102](0102-scoped-top10-profile-excerpts.md)의 공개용 저장 발췌26프로필에서 자산+네트워크2~3개를 고르고, 식별자·검토 범위·검토일·기능 조건·근거를 표시한다. ‘검증 비교’는 기존 STORED_READ_ONLY 보고서2~3개의 capability·시나리오·원래 판정/지원/실행 상태와 문서 연결을 유지한다. 보기 전환으로 선택을 재설정하지 않는다.

프로필별 `scope-0` 같은 id는 서로 다른 의미일 수 있으므로 조인 키로 사용하지 않는다. 검토 그룹과 항목명이 정확히 같은 경우만 같은 행에 두며, 합쳐진 전송/승인 항목을 기존 개별14기능에 억지로 분해하지 않는다. 같은 이름도 실행 의미의 동등성을 보장하지 않는다. 미수록·추가 검토·해당 없음·검토 경로의 부재를 구분하고 PASS/FAIL이나 점수·순위를 새로 만들지 않는다.

## 경계와 검증

정적 공개 발췌와 기존 로컬 근거 GET만 사용한다. 새 외부 조회·RPC·compiler·키·DB 변경은 없다. 보고서 읽기 실패에도 정적 프로필 비교는 동작하며 기존 정상 보고서·시각·선택을 유지한다. 중복 선택은 선택지에서 차단하고 모델에서도 거부한다. 수행·검증·재현은 [작업 기록](../research/2026-10-25-comparison-workspace.md)을 따른다.
