# ADR0116: 저장 전송 활동 지표 비교

- 상태: 사용자 승인, 2026-10-28
- 배경: 전송금액만으로 네트워크의 활동 빈도나 전송 규모 분포를 판단하기 어렵다. 사용자 요청에 따라 기존 저장 자료에서 직접 관측 가능한 지표를 나란히 표시한다.

## 결정

전체 현황의 기존 토큰 전송량 그래프를 유지하고 USD 전송금액·전송 이벤트 건수·전송 포함 트랜잭션 수 선택을 추가한다. 같은 선택 자산/공급자 snapshot/집계일의 네트워크 비교표에 USD 금액·두 건수·전송 이벤트당 평균 USD를 제공한다. 새 공급자 호출이나 DB/서버 API 변경 없이 기존 검증된 survey DTO를 사용한다.

단위는 축/툴팁/요약 카드/범례/접근성 설명에 함께 적용한다. 비중은 선택 지표의 관측된 표시 네트워크 부분합만 사용하고 관측 대상 수·숨김 수를 표시한다. 같은 토큰의 체인별 값을 비교하며 토큰별 트랜잭션 수를 합쳐 네트워크 전체 고유 트랜잭션 수로 만들지 않는다.

평균은 동일 행의 공급자 USD 전송금액 ÷ 전송 이벤트 수다. bigint/36자리 십진 계산 후 소수2자리까지 표시하고 이하 자릿수는 버린다. 양의 0.01 미만 값은 `<0.01`로 표시한다. 분모0·값 누락은 미산정, 원래0은0으로 유지한다. 원문 금액/건수·분자/분모·관측일·조회시각/출처는 보존한다. 평균을 합산하거나 도넛 비중으로 사용하지 않는다.

## 한계와 경계

PROVIDER_DAY와 집계 시간대 UNKNOWN을 유지하고, 누락일/네트워크를 다른 날짜의 최신값이나0으로 채우지 않는다. 평균은 중앙값/결제 객단가가 아니며 높은 빈도는 봇·DEX·반복 이동을 포함할 수 있다. 안전성·고래/사람 수·결제량으로 승격하지 않는다. 활성 주소/중앙값/금액대별 건수/DEX 전체/결제 분류는 미확보로 표시한다.

새 API/키·Arkham 소비 재실행·Supabase schema/grant/import·Collector/FX·수집 주기·운영 Mac mini 직접배포는 제외한다. Safari 호환 JSON 읽기/캐시/보안 정책은 기존 경로를 그대로 사용한다.

## 검증

정확한 큰 건수·36자리 소수·2자리 절사/0/null/누락일·지표 혼합 거절을 모델 시험으로 확인한다. 오프라인 Chrome의 두 테마/1440px·390px·Safari API 부재 조건에서 단위/날짜/숨김/미확보 지표 복구와 추가 JSON 요청0을 확인하고 npm run check를 실행한다. 실제 iPhone/WebKit 시험과 Chrome 조건 모사는 구분한다.
