    현재 총공급량 · totalSupply · tokens

      점수·등급 산정 기준

      정책 SCENARIO_SUCCESS_V1 · 확정 판정 중 시나리오 통과 비율입니다. 자산 안전성·지원 등급을 뜻하지 않습니다.

      통과 점수 = PASS ÷ (PASS + FAIL) × 100, 소수점 버림. 판정 완료 비율 = (PASS + FAIL) ÷ (NOT_APPLICABLE 제외 항목) × 100입니다. INCONCLUSIVE·NOT_TESTED·UNSUPPORTED는 통과로 취급하지 않으며 별도로 표시합니다. 판정 완료 항목이 없으면 점수·등급이 없습니다.

      등급은 A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, F < 60입니다. 미확인·미실행 항목이 남으면 잠정 등급입니다. 실제 자산 읽기와 사설 Fixture는 분리하며 같은 자산·체인 식별자의 최신 보고서만 집계합니다. 점수는 선택된 시나리오의 통과 비율이며 자산 안전성·신용도·금융기관 취급 승인이 아닙니다.

      유통량, 현재 총공급량, 기간 중 신규 발행량은 다른 지표입니다. 이 화면의 총발행량은 공급자의 현재 totalSupply이며 기간 중 민팅·소각 흐름을 뜻하지 않습니다. XRPL obligations를 더하거나 차감하지 않습니다. totalVolume은 기간·단위가 확인되지 않아 순위를 만들지 않습니다.

        XRPL의 obligations는 범위가 제한된 별도 지표입니다. 총공급량 순위에 넣지 않으며, 운영주소 제외·유통량을 검증한 값이 아닙니다. 네이티브·브리지 구분과 공급자 산정 방식도 독립 검증하지 않았습니다.

        네트워크 활성 표시는 공급자 보고값입니다. 원장의 실제 정상 동작을 보증하지 않으며, 표시된 시각은 해당 네트워크 관측에만 적용됩니다.
