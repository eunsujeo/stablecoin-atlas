    순위 · 네트워크통과 점수판정 완료

      통과 점수 = PASS / (PASS + FAIL), 판정 완료 = (PASS + FAIL) / 비적용 제외 항목. 미산정은 순위를 부여하지 않으며 정확한 비율이 같으면 공동 순위입니다. 항목 구성과 표본 수가 서로 다릅니다. 행을 누르면 해당 근거를 봅니다.

      점수·등급 산정 기준

      정책 SCENARIO_SUCCESS_V1 · 확정 판정 중 시나리오 통과 비율입니다. 자산 안전성·지원 등급을 뜻하지 않습니다.

      통과 점수 = PASS ÷ (PASS + FAIL) × 100, 소수점 버림. 판정 완료 비율 = (PASS + FAIL) ÷ (NOT_APPLICABLE 제외 항목) × 100입니다. INCONCLUSIVE·NOT_TESTED·UNSUPPORTED는 통과로 취급하지 않으며 별도로 표시합니다. 판정 완료 항목이 없으면 점수·등급이 없습니다.

      등급은 A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, F < 60입니다. 미확인·미실행 항목이 남으면 잠정 등급입니다. 같은 자산·체인 식별자의 최신 보고서만 집계합니다. 점수는 선택된 시나리오의 통과 비율이며 자산 안전성·신용도·금융기관 취급 승인이 아닙니다.

      유통량, 현재 총공급량, 기간 중 신규 발행량은 다른 지표입니다. 이 화면의 총공급량은 공급자의 현재 totalSupply이며 기간 중 민팅·소각 흐름을 뜻하지 않습니다. XRPL obligations를 더하거나 차감하지 않습니다. totalVolume은 기간·단위가 확인되지 않아 순위를 만들지 않습니다.
